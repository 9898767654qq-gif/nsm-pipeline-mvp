# NSM-PIPELINE MVP

Прототип для теста: совместный разговор на объекте превращается в протокол, ТЗ и спецификацию.

Правило продукта: **термин не входит в договор, пока у него нет простого ядра и фразы согласия.**

Репозиторий: https://github.com/9898767654qq-gif/nsm-pipeline-mvp

## Как открыть и протестировать

Не нужен Node и не нужен ключ LLM.

```bash
git clone https://github.com/9898767654qq-gif/nsm-pipeline-mvp.git
cd nsm-pipeline-mvp
python3 -m http.server 8765
```

Откройте http://localhost:8765

Либо просто откройте `index.html` в браузере.

Если включён GitHub Pages: https://9898767654qq-gif.github.io/nsm-pipeline-mvp/

## Что проверять

1. Кнопка **Демо: климат**. Должен появиться рекуператор с ядром свойств, условие «не в спальне», отказ от шума.
2. Кнопка **Демо: гараж 6×6**. Праймер, гидроизоляция, вентиляция идут как технология подрядчика. Благоустройство — отказ.
3. Оставьте в тексте только «ставим рекуператор» без свойств. Прогоните снова.
4. Скачайте протокол / ТЗ / спецификацию / JSON.

## Что это не умеет

- Боевое распознавание речи.
- ЭЦП, Гранд-Смета, ФЕР, КС-2.
- Полный строительный словарь.
