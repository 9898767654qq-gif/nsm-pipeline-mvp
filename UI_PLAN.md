# Согласованный план интерфейса

Цель экрана: человек за минуту понимает, *что будут делать с домом*, а не какая модель «умная».

Тон: тёплый технический. Кремовый фон, угольные буквы, терракотовый акцент.

## Принципы

1. Свойства крупно, термин мелко.
2. Один экран — одно действие.
3. Жёлтое и красное важнее зелёного.
4. Подпись недоступна, пока есть блокирующая неясность.
5. Мобильный осмотр важнее десктопной красоты.
6. Никакого «AI generated» в лице продукта.

Полный план экранов, состояний и очереди работ — в репозитории после следующего коммита с полным текстом.
